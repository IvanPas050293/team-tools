# Сохранение git log в git_log.txt

Сохранение истории коммитов (одна строка на коммит) в файл `git_log.txt` в корне проекта.

## Шаги

1. Определить корень проекта (каталог, где запущена сессия). Если текущий каталог — подпапка, сначала перейти в корень проекта.
2. Выполнить через Bash-инструмент (Git Bash на Windows):
   ```
   git log --oneline > git_log.txt
   ```
   Перенаправление `>` перезаписывает `git_log.txt`, если он уже существует — удалять файл заранее не нужно.
3. Проверить результат: прочитать `git_log.txt` и убедиться, что в нём строки коммитов.
4. Если `git log` завершился ошибкой (например, каталог не является git-репозиторием) — сообщить об ошибке пользователю, а не создавать пустой файл.
